## Сигнатура

```python
generate_wb(
    amount,                    # целые рубли: 12 / "12 ₽" / "1 000 ₽"
    operation_dt,              # datetime МСК (naive = МСК)
    recipient_name,            # ФИО → «Имя Отчество Ф.»
    recipient_phone,           # любой RU → «+7 XXX XXX-XX-XX»
    recipient_bank,            # «Альфа-Банк» / «Т-Банк» / «ВТБ» / …
    output_path=None,          # иначе banks/wb/out/<uuid4>.pdf
    *,
    sender_name=None,          # игнорируется (поля нет)
    sender_phone=None,         # игнорируется
    donor_path=None,
    donor_pool_dir=None,
    token_registry_path=None,
    generated_at=None,         # CreationDate; по умолчанию now
    sbp_id=None,               # иначе перевыпуск по правилам донора
    receipt_no=None,           # иначе счётчик CreationDate
) -> Path
```

## Поля чека

Значения Regular 17 pt, правый край **x = 555** (OpenPDF
`formatDouble`). Сумма Medium 55.5 и дата Regular 17 — **центр
x = 297.5**. Квитанция Bold 14 — слева x = 40. СБП-id переносится
при ширине **245 pt** (бокс 555−245).

| Поле | Формат | Шрифт |
|---|---|---|
| сумма | `13 ₽` (без копеек, тысячи пробелом) | Medium 55.5, центр |
| дата | `ДД.ММ.ГГГГ ЧЧ:ММ:СС` (без UTC+3) | Regular 17, центр |
| вид | `Перевод по СБП` | не меняется |
| статус | `Выполнено` | не меняется |
| получатель | `Имя Отчество Ф.` | Regular, вправо |
| телефон | `+7 XXX XXX-XX-XX` | Regular, вправо |
| банк | справочник СБП | Regular, вправо |
| ИД СБП | 32 символа, 2 строки | Regular, вправо, wrap 245 |
| квитанция | `Квитанция № ##########` | Bold 14, слева |
| подвал | `По вопросам зачисления…` | не меняется |

Печатное время = момент в СБП-id (UTC→МСК) **+ 1 секунда** у всех
четырёх доноров.

## ИД СБП

Как у Яндекса (наследование серийника, не случайная сборка сегментов):

```
[A|B донора] + stamp(UTC, printed − 1с) + donor[11:22] + era_tail
```

- `stamp` = последняя цифра года UTC + день года UTC (3) + `ЧЧММСС` UTC
- `donor[11:22]` — одноразовый серийный токен (реестр
  `donors/spent_tokens.json`)
- хвост с 06.11.2026: `0011890101` (у всех четырёх доноров; маркер
  эпохи `0G` живёт внутри унаследованного серийника)

## Номер квитанции

10-значный счётчик с префиксом `10221…`, привязан к **CreationDate**
(момент выгрузки), не к операции. Между донорами ~1.36–1.89/с
(среднее ≈ 1.6/с). Движок якорит на корпусе и инкрементирует, пока
все цифры не попадут в Bold-пул `0125789` (глифов 3, 4, 6 в Bold нет).

`CreationDate` генерации — момент `generated_at` в UTC (`D:…Z`).
mtime файла = CreationDate + 1 с. Trailer `/ID` свежий, парный.

Сохранение: natural-save через `rocket_pdf` (inplace, иначе refit
с `>>stream`, один `startxref`/`%%EOF`, без `/Prev`). Сабсеты
Google Sans обрезаются до использованных глифов, 6-буквенные теги
перевыпускаются. Glyf в слот GID копируется **сырыми байтами**
(не fontTools save — иначе сдвинется `head.modified` и порядок таблиц).

## Ограничения глифов (пул четырёх доноров)

Доращивание разрешено только глифами **этих** чеков, тем же CID=GID.

| Начертание | Есть в пуле | Нет |
|---|---|---|
| Medium (сумма) | `0 1 2 3 ₽` и пробел | цифры **4–9**, запятая, точка |
| Regular (поля) | `0-9 +-. : A B G` и `АБВГЕЖИЛНПСТЧШЬЯ` + строчные `абвгдезийклмнопрстуфцчщыьюя` | заглавные **Д З Й К М О Р У Ф Х Ц Щ Ы Э Ю Ё**, строчные **ё ж х э**, прочая латиница |
| Bold (квитанция) | `Квитанция №` + цифры **0125789** | цифры **3 4 6** |

Следствия:

- сумма — **только целые рубли** из цифр 0–3 (`10`, `12`, `13`, `20`,
  `123`, `1 000`, `2 000`…); `15 ₽` и `12,50 ₽` — отказ;
- «Сбербанк» и «Александр Евгеньевич Ж.» набираются; «Константин»
  (заглавная **К** только в Bold), «Ёлкина», «Озон Банк» (**О**),
  «МТС» (**М**) — отказ, пока в пул не положат настоящий чек с этими буквами;
- отправитель в чеке не печатается, аргументы `sender_*` отбрасываются.

## Бот

Подключён в `bot/yandex_bot.py`. В главном меню [ВБ Банк] → только
[Чек СБП] (`generate_wb`). Сумма — целые рубли; `sender_*` бот не
передаёт. GlyphCoverageError / NoUnusedDonorTokenError — короткое
«Не получилось: …», возврат в сводку. Токены одноразовые, бот их не
обходит.

`python3 banks/wb/test_engine.py`: round-trip доноров байт-в-байт,
совпадение переноса СБП с донором, generate_wb (поля, SBP = printed−1с,
наследованный серийник, одноразовый токен, квитанция, один startxref),
доращивание Medium `2` для `20 ₽` и группировка `1 000 ₽`, отказы
(Ё, цифра 5 в сумме, копейки, заглавная К, повтор токена).
